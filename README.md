# 应援三消网页游戏

纯静态网页，可直接部署到 GitHub Pages。主色：`#027789`。

## 已完成的玩法

- 两关制：第 1 关通关后自动解锁更难的第 2 关。
- 三条生命；每条生命都可答一次题，答对随机获得「消除」「暂存 3 张」「洗牌」道具。
- 消除槽固定为 72px 高；暂存区始终预留空间，不会使消除槽上下移动。
- 完成两关后，以从第 1 关开始计算的总用时写入本机排行榜。
- 成功三消时有网页合成音效，无需额外音频文件。

## 图片压缩

原 PNG 保留在 `images/`；游戏使用 `images/cards/` 内的 512×512 JPG 压缩副本，每张约 28–64 KB。

## 背景音乐

页面已配置音乐开关和 `assets/bgm.mp3` 路径。请将**你拥有使用授权**的音频命名为 `bgm.mp3` 放进 `assets` 文件夹；点击右上角音符即可播放。项目未包含《羊了个羊》原版 BGM。

## 发布到 GitHub Pages

1. 创建公开仓库，例如 `sheep-game`。
2. 上传本文件夹全部内容，包含 `images/cards` 与 `assets`。
3. 在 **Settings → Pages**，选择 **Deploy from a branch**、`main`、`/(root)`，保存。
4. 等待 1–3 分钟，访问 `https://你的用户名.github.io/sheep-game/`。
